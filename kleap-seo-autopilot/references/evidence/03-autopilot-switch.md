Autopilot is on for Hotel Kleap Prod Check. The setting is saved inside your site, so any machine that runs this skill will now apply fixes without asking first. The skill doesn't install the schedule itself; here are the setup steps for this Mac (launchd runs the job; the command was generated by `scripts/seo-schedule.mjs`):

**1. Create an API key file only you can read.** Make a key with the **Full** preset at https://kleap.co/settings/api-key, then run this and paste the key where shown. Don't paste the key into this chat.
```bash
mkdir -p ~/.kleap-seo/reports && install -m 600 /dev/null ~/.kleap-seo/env
echo 'export KLEAP_API_KEY=<your key>' >> ~/.kleap-seo/env
```

**2. Tell the schedule which site to run on.** This session kept its files in a temporary folder (`/tmp/fresh-it3-t1/seo-home`), but the scheduled job reads `~/.kleap-seo`:
```bash
echo hotel-kleap-prod-check.kleap.io >> ~/.kleap-seo/sites.txt
```

**3. Make the skill available outside this folder.** Right now it's installed only in `/private/tmp/fresh-it3-t1/.claude/skills`. The scheduled job doesn't start in that folder, so it won't find the skill, and anything under `/tmp` can be cleared when the Mac restarts. Copy it somewhere permanent:
```bash
mkdir -p ~/.claude/skills && cp -R /private/tmp/fresh-it3-t1/.claude/skills/kleap-seo-autopilot ~/.claude/skills/
```

**4. Install the daily run (7:07 every morning).** Save the plist printed above as `~/Library/LaunchAgents/co.kleap.seo-autopilot.plist`, then:
```bash

```

- On a quiet day the report is one line; on Mondays you get the full weekly report plus one growth idea.
- It never creates new pages without your yes.
